## InventoryBackpack.png

Use case: stylized-concept. Asset type: single inventory icon for a Frutiger Aero game UI. Create a pristine glossy translucent aqua-blue backpack with a pearl white shell, a lime-green leaf-shaped zipper pull, rounded tactile forms, bright glass highlights and soft internal reflections, like a polished 2005 nature-and-technology desktop icon. Straight-on three-quarter view, centered, square composition with generous transparent padding, readable silhouette at 48px. The backpack alone with no surrounding tile, no text, no letters, no watermark, no environment. Genuine transparent background.

Transparency: enabled. Generated with the built-in image tool. Project asset: `Assets/_Project/UI/FrutigerAero/Art/InventoryBackpack.png`; indexed copy: `Frutiger Reference/Asset/InventoryBackpack.png`.

## InventorySmall.png

Create a SMALL UI ICON, target native display 68 by 68 pixels, for a Frutiger Aero inventory button. Request a 68x68 PNG if output size is controllable. Design directly on a 68-pixel visual grid, NOT a detailed illustration reduced to thumbnail. Subject: one front-view backpack, simple rounded aqua-blue body, single broad white top highlight, thick dark-cyan edge, a single lime-green rectangular pocket. Only 3 or 4 large shapes: body, handle, pocket, highlight. At the 68px design scale: outline 2px thick, handle gap 8px wide, no feature smaller than 4px. Broad soft glossy blue and white gradients, like the simple icons on a 2005 nature dashboard. The silhouette must be immediately readable at 36px too. Centered, generous transparent margin. No tiny zippers, straps, fabric, bubbles, texture, scenery, sparkles, micro-reflections, intricate translucency, perspective, text or enclosing tile. Clean UI sprite on a truly transparent background.

## UpgradesSmall.png

Create a SMALL UI ICON, designed directly for a 68 by 68 pixel Frutiger Aero Upgrades button. Request a 68x68 PNG if the output size is controllable. This is a tiny interface symbol, not a macro illustration to shrink. One bold upward-pointing lime-green arrow with a thick deep-cyan outline rises from a single rounded aqua-blue step at its base. Only two large recognizable shapes plus one broad white gloss highlight on each. Front view, balanced centered square silhouette. At the 68px design scale use 2px thick outlines, arrow shaft 12px wide, large arrow head 36px wide, no feature smaller than 4px. Broad blue/green gradients, simple 2005 glossy dashboard icon. Clear at 36px. Transparent padding around silhouette, genuinely transparent background. No bar chart, no multiple glass blocks, no bubbles, no sparkles, no tiny details, no caustics, no intricate refraction, no scenery, no perspective, no text, no enclosing tile.

Both icons were generated with the built-in image tool, transparency enabled. The generator returned a large source canvas despite the requested small output, so the designs use a small visual grid and are imported as uncompressed 64 × 64 textures. The source PNGs are kept in `Assets/_Project/UI/FrutigerAero/Art/`, with indexed reference copies in `Frutiger Reference/Asset/`. These replace the detailed InventoryBackpack and UpgradesGrowth images in the active UI.
