# Action icon generation prompts

Generated with the built-in image generation tool, transparency enabled. Designs match InventorySmall.png and UpgradesSmall.png and are reused through GatherActionIcon, ProcessActionIcon, and BuildActionIcon prefabs in both upgrade tabs and interaction prompts.

The tool returned large source canvases; Unity imports these simple silhouettes as uncompressed 64 × 64 sprites for 36–68 unit controls. Source artwork is preserved in Assets/_Project/UI/FrutigerAero/Art/ and indexed in Frutiger Reference/Asset/.
