# F3 developer controls

Press **F3** to open or close the cheat menu. **Escape** closes it too. The cursor becomes available while it is open, and normal cursor and player controls return when it closes. The menu uses unscaled time and can be reopened while the simulation is paused.

Start a session with **Start local host** in Quick actions, or use the existing F1/F2 connection shortcuts. Gameplay changes travel through the existing network services and their authoritative replies update the menu and inventory. No typed project cheat commands remain in the debug console.

## Controls

- **Quick actions:** level up, gain XP, toggle instant asset building or god mode, build the next unfinished floor, increase bag capacity, start a local host.
- **Progression:** choose Gather, Process, Build or **ALL**. ALL applies level, XP, points, selected reset and matching-position node purchases to every profession. It also applies a profession speed/production/cost preset across the three classes. Selecting a single profession restores individual actions. Current level, XP and points are displayed above the list.
- **Construction:** **Instantly build asset** is a persistent on/off toggle. Enabling it builds nothing by itself; while enabled, pressing E on an available asset finishes all ten stages without cost or delay. It retains the floor unlock rules. **Instantly build floor** resolves the next unfinished floor on the server each time, independently of the player's standing floor and the floor number field. Repeated presses advance the tower. The number field still selects the floor for reset and teleport. Advance/reset captured assets, or complete/reset the whole tower with the other controls.
- **Inventory:** add raw stone, processed stone, sand, glass, or river, water and sky essences and blocks, fill or clear the bag, increase capacity, instantly gather the captured resource, instantly process at the captured machine, respawn all resources. Processing still consumes its recipe input; the glass kiln uses 2 sand for 1 glass, and each essence processor (river mill, water press, sky spinner) uses 2 essence for 1 block.
- **Stats:** movement, sprint and crouch speeds, acceleration, air control, jumping, gravity, extra jumps, mouse sensitivity, camera field of view, gathering/processing/construction speeds, production, processing/construction costs, bag capacity, XP multiplier and resource respawn speed. Multipliers have direct presets; numeric fields support exact values. Reset restores defaults. Construction production controls the number of stages built per normal action. Gathering has no input-cost stat.
- **World:** teleport to a tile on the selected unlocked floor, return to the opening position, toggle **God mode**, set local time scale, scan construction, cancel the current action. God mode flies with WASD, Space to ascend, Ctrl to descend and Shift to accelerate. It disables normal movement/gravity and every player collider, including the separate capsule and CharacterController. Closing F3 preserves flight; turning it off or removing the menu restores each previous collider state and normal movement.
- **Animations:** play each available character action and stop the current animation.

Choose an amount with the 100 / 1000 / 10000 presets or enter a value. Floor numbers start at 1. Aim at an asset, resource or processor before opening F3 to capture it; if nothing is targeted, the nearest unfinished construction within 15 metres is selected. The target and bag capacity are shown above the list. Search finds actions across categories, while the category tabs provide a shorter list.

Bag capacities are independent for each player and resource, with a maximum of 1,000,000. Reducing capacity clamps existing amounts. Stat multipliers are clamped to valid finite values, and the normal minimum resource cost is one. Cheat stat overrides reset when the session stops.
